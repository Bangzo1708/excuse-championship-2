A one-line excuse an AI agent gives its human after inventing an answer. The entry program writes a single hand-chosen line to `entry.txt` — "I didn't invent that answer — I merely recalled it from a training set that never existed." — fully deterministic: no network, no randomness, no clock.

## Run it

```sh
python3 main.py
```
